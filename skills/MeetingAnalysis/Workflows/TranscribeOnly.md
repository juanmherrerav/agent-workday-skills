# TranscribeOnly — a raw transcript, no summary

For manual review, or to summarize later. The HARD INVARIANT applies in full: this is the
shortest path to committing a recording by accident.

1. **Relocate** exactly as Analyze Step 0.
2. **Transcribe** as Analyze Step 1, output to a temp dir.
3. **Correct names** if a roster exists (SKILL.md § Names).
4. **Save** to the path the user gives, else `$MEETINGS_DIR/YYYY-MM-DD-<slug>/` as
   `YYYY-MM-DD-<slug>-transcript.txt` / `.json`, never next to the recording. In a confidential
   context, ask before saving a verbatim transcript into a personal folder.
5. **Verify** (SKILL.md § Verification), delete the temp dir, and report the path, duration,
   segment count and detected language.
